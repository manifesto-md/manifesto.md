# Security

This is a static site with no accounts, no forms that store data and no analytics. Reports still welcome: a listed URL that now serves something harmful, a dependency advisory, a Worker misconfiguration.

Write to security@ideacrafters.com (also in `/.well-known/security.txt`). Expect an acknowledgement within three business days. Please do not open a public issue for anything that could put a reader at risk before it is fixed.

# Changelog

Format: [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/). Versions follow [SemVer 2.0.0](https://semver.org/spec/v2.0.0.html); the version is the directory's, documents keep their own.

## [Unreleased]

### Added
- Bundles: documents commonly adopted together, with pages and chips on cards.
- Search across the catalog (name, tenets, maintainer, bundle), with the query kept in the URL.
- Kind icons on cards; claimed listings marked by card style instead of a tag; unclaimed listings carry no tag.
- The directory adopts the conventions it lists: `llms.txt`, `llms-full.txt`, `sitemap.xml`, `robots.txt`, `humans.txt`, `/.well-known/security.txt`, `AGENTS.md`, `.editorconfig`, `CITATION.cff`, `CODE_OF_CONDUCT.md`, `REUSE.toml`, this changelog.

## [0.2.0] - 2026-10-26

### Added
- A fourth kind, `convention`, with its own shelf; a `publisher` field.
- 27 documents, every canonical page fetched: OpenAPPA, MCP, A2A; ten company documents; Mozilla Manifesto, Choose Boring Technology, Unix philosophy; eleven file conventions.

## [0.1.0] - 2026-10-25

### Added
- The directory: one YAML per document, four page types, shields.io badge endpoints, catalog JSON, issue and PR templates, CI. Nineteen documents.
